Privacy Policy – OpenClaw Personal Assistant

Effective date: November 12, 2026

About this tool

OpenClaw Personal Assistant is a private, single-user tool operated by Orielsy Diaz. It is for personal use only, not a public service.

Google account access

The assistant uses Google OAuth only to access my own Google account data. It does not request access to anyone else's Google account.

How data is used

Google account data is used only to provide the assistant's features to me, on my own machine.

Sharing and advertising

Google user data is not sold, shared with third parties, or used for advertising.

Google API data policy

Use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

Revoke access

I can revoke the assistant's access to my Google account at any time through Google Account permissions.

Contact

Questions about this policy: orielsydiaz@gmail.com.
